# HomeCore logo — integration notes

Instructions for adding the HomeCore logo to the `grzegorz-grzeda/home-core` repository.

## Files

| File | What it is | Size |
| --- | --- | --- |
| `homecore-logo.svg` | The mark alone (house-shaped chip with a `>_` prompt). | 55 × 55 px, viewBox 120 × 120 |
| `homecore-logo-wordmark.svg` | Mark plus the "HomeCore" wordmark. | 460 × 120 px |

Both files are plain, dependency-free SVG. They adapt to dark mode on their own: an internal
`@media (prefers-color-scheme: dark)` rule switches the dark ink (`#16202A`) to off-white
(`#F2EEE5`). The copper accent (`#C8692B`) stays the same in both modes.

The wordmark uses live SVG text with a monospace font stack (IBM Plex Mono first, falling
back to the system monospace font). `textLength` keeps its width fixed whichever font renders.

## Tasks

1. Copy both SVGs into the repository under `docs/assets/` (create the directory if it
   does not exist). Keep the file names.

2. Doxygen header logo. Find the project's Doxyfile (search the repo for a file
   containing `PROJECT_NAME`; it may be generated by CMake from a `Doxyfile.in`). Set:

   ```
   PROJECT_LOGO = docs/assets/homecore-logo.svg
   ```

   The path is relative to the directory Doxygen runs from. If the Doxyfile is a CMake
   template, use `@PROJECT_SOURCE_DIR@/docs/assets/homecore-logo.svg` (or the variable the
   template already uses for other paths). Doxygen 1.9.8 copies the file into the HTML
   output and shows it left of the project name at its native 55 px height.

3. README header. At the top of `README.md`, above or replacing the existing title:

   ```html
   <p align="center">
     <img src="docs/assets/homecore-logo-wordmark.svg" alt="HomeCore" width="360">
   </p>
   ```

4. Verify. Rebuild the docs with the project's existing docs target or command, and
   confirm that `homecore-logo.svg` appears in the HTML output directory and that
   `index.html` references it in the header. Do not change any other Doxygen settings.

## Rules

- Do not edit the SVG geometry or colors.
- Do not add raster copies (PNG/ICO) unless asked.
- Do not commit or push unless the user asks.
